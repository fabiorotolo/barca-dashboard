🔒 Cifra le chiavi delle dashboard

Tutto avviene in questo browser: password e chiavi non vengono inviate da nessuna parte. Il risultato è illeggibile senza password e va copiato nel file chiavi-cifrate.js di barca-dashboard e di meteo-dashboard (stesso contenuto nei due).

Contenuto completo di chiavi-cifrate.js:

Incolla il risultato nella chat con Claude, che lo carica in barca-dashboard e meteo-dashboard. Oppure su GitHub apri chiavi-cifrate.js in ciascun repository → matita ✏️ → sostituisci tutto → Commit changes. Dopo un paio di minuti apri una dashboard e, se richiesto, reinserisci la password.
